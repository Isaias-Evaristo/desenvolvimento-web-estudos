# Notas: CSR, SSR e SSG

## O que é CSR?

 É quando o servidor entrega os ingredientes e o navegador monta a página. Nesse modelo, a página chega quase vazia e o JavaScript monta o conteúdo na tela do usuário.

## O que é SSR?

 É quando o servidor monta a página e a entrega pronta para o navegador. A cada pedido, a página já chega completa para o usuário.

## O que é SSG?

 É a página montada antes, uma vez só, na hora de publicar o site. O servidor só entrega a página que já estava pronta.

## Qual dos três a minha página do GitHub Pages usa e por quê?

Minha página no GitHub Pages usa SSG, porque a página é montada antes da publicação do site. Quando o usuário acessa, o servidor apenas entrega os arquivos que já estão prontos, sem precisar gerar a página a cada requisição.
