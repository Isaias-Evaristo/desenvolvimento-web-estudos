# Renderização: CSR, SSR e SSG

Anotações sobre onde e quando uma página web é montada.

## O que foi estudado

- CSR: a página é montada no navegador
- SSR: a página é montada no servidor a cada pedido
- SSG: a página é montada antes de publicar
- Qual deles o GitHub Pages usa nas minhas páginas
