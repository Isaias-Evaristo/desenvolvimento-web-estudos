# HTML

Mini-projeto da disciplina de Desenvolvimento de Aplicações para Internet: uma página de apresentação pessoal.

## Ver a página

[Abrir a página publicada](https://isaias-evaristo.github.io/desenvolvimento-web-estudos/02-html/)

## O que foi praticado

- Estrutura básica de uma página HTML
- Títulos, parágrafos e links
- Imagem com legenda (`figure` e `figcaption`)
- Lista (`ul` e `li`)
- Tabela (`table`, `thead`, `tbody`, `tr`, `th` e `td`)
- Tags semânticas (`header`, `main`, `section` e `footer`)

## Arquivos

- `index.html`: a página
- `foto.jpeg`: a imagem usada na página

## Como abrir

Dê dois cliques no `index.html` para abrir no navegador.
