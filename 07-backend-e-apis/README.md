# Back-end e APIs

Primeiros passos com um servidor feito em JavaScript, usando Node.js.

## O que foi praticado

- Criei um servidor com o módulo `http` do Node.js
- Rotas: responder diferente conforme o caminho (`/`, `/sobre`)
- Requisição e resposta
- Código de status 404 para rota não encontrada
- API: rota `/api/tarefas` que devolve dados em JSON

## Como rodar

1. Instale o Node.js
2. No terminal, rode: `node 07-backend-e-apis/servidor.js`
3. Abra `http://localhost:3000/api/tarefas` no navegador
4. Para desligar, aperte `Ctrl+C`

## Arquivos

- `teste.js`: primeiro teste do Node.js
- `servidor.js`: o servidor com a API
