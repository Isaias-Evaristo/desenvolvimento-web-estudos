# JavaScript

Exercícios de JavaScript básico, testados no Console do navegador.

## O que foi praticado

- Variáveis com `let` e tipos (texto, número e verdadeiro/falso)
- Operadores: `+`, `-`, `*`, `/` e `%`
- Condições com `if` e `else`
- Laço `for` (de 1 a 10 e só os pares)
- Funções com parâmetros (`saudacao` e `somar`)

## Arquivos

- `index.html`: a página que carrega o código
- `script.js`: os exercícios
