 # DOM e eventos

Exercícios em que o JavaScript muda a página quando o usuário clica em um botão.

## O que foi praticado

- Achar um elemento da página com `document.getElementById`
- Mudar o texto de um elemento com `textContent`
- Mudar a cor de um elemento com `style.color`
- Reagir a um clique com `addEventListener("click", ...)`
- Alternar entre dois estados usando `if` e `else`

## Arquivos

- `index.html`: a página com o parágrafo e o botão
- `script.js`: o código que troca o texto e a cor
